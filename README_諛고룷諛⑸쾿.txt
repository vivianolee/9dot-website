9DOT 홈페이지 파일
===================

도메인: https://9dot.life
형태: 정적 반응형 홈페이지(HTML/CSS/JavaScript)
서버 프로그램이나 데이터베이스 없이 저렴하게 운영할 수 있습니다.

폴더 구성
- index.html : 홈페이지 본문
- styles.css : 디자인
- script.js : 모바일 메뉴와 화면 효과
- assets/favicon.svg : 브라우저 아이콘

배포 전 꼭 수정할 곳
1. index.html의 hello@9dot.life
   실제 사용할 이메일이 다르면 전체 검색하여 바꾸세요.
2. 푸터의 "사업자등록번호: 법인 설립 후 입력"
   사업자등록이 끝나면 번호를 넣으세요.
3. 울타리/KASA 소개가 외부 공개 전이면 문구나 상태를 수정하세요.

가장 쉬운 배포 방법
1. 9dot-website 폴더 안의 파일을 모두 압축합니다.
2. Netlify, Cloudflare Pages, GitHub Pages 같은 정적 호스팅에 업로드합니다.
3. 호스팅 서비스에서 발급된 주소로 홈페이지가 정상 표시되는지 확인합니다.
4. 도메인을 구입한 업체의 DNS 관리 화면에서 호스팅 서비스가 안내한 레코드를 입력합니다.
5. HTTPS 인증서가 활성화되면 https://9dot.life 로 접속합니다.

주의
- 도메인만 구입했다고 홈페이지가 자동으로 표시되지는 않습니다.
- 홈페이지 파일을 올려둘 호스팅이 필요합니다.
- 무료 정적 호스팅을 사용하면 현재 홈페이지는 월 서버비 없이 운영할 수 있습니다.
- 문의 메일 hello@9dot.life 를 쓰려면 별도로 도메인 이메일을 개설해야 합니다.
